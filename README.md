# SQL-task_Window-function
Performed various SQL operations using Window Functions to analyze data across related rows without grouping them into a single row.

Used ROW_NUMBER() to assign unique numbers to rows.

Used RANK() and DENSE_RANK() to rank records based on specific columns.

Used LAG() and LEAD() to compare current values with previous and next rows.

Used SUM(), AVG(), MIN(), and MAX() as Window Functions for analysis.

Applied PARTITION BY to perform calculations within specific groups.

Used ORDER BY within Window Functions to define the order of calculations.
